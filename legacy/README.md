# Legacy coursework

This directory preserves the original OpenGL/freeglut coursework separately
from the reusable renderer and the newer `LabX` experiments.

- `2022CG_Lab2`: 2D polygon filling, viewport transforms, and clipping.
- `2022CG_Lab3`: the software 3D transformation and rasterization pipeline.
- `2022CG_Lab4`: Z-buffering and Flat, Gouraud, and Phong shading.

These applications intentionally keep their original data and mesh directory
layout. CMake sets the matching working directory for Visual Studio launches.
Lab 1 is not present because its standalone source was never preserved.
