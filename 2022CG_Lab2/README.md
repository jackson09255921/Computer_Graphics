# Lab 2 — 2D Rasterization

This lab implements polygon filling, viewport transformations, and 2D clipping.

From the repository root, build with CMake, then run with this directory as the
working directory:

```bash
../build/lab2 lab2D.in
```

Available inputs are stored in [`Data/`](Data/). Press <kbd>Enter</kbd> to step
through commands from the selected input file.
