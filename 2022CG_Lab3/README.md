# Lab 3 — 3D Rendering Pipeline

This lab adds OBJ loading, model/view/projection transformations, perspective
division, 3D clipping, back-face culling, and CPU rasterization.

From the repository root, build with CMake, then run with this directory as the
working directory:

```bash
../build/lab3 Lab3B.in
```

Input scenes live in [`Data/`](Data/) and reference models in [`Mesh/`](Mesh/).
Press <kbd>Enter</kbd> to step through the scene commands.
